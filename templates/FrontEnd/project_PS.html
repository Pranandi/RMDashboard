Server Patch Management: Ensuring Security, Compliance, and Threat Mitigation

Summary

Comprehensive OS Patch Management Procedure: Automated and Manual Steps with Pre-Checks, Post-Checks, Troubleshooting, and Fallback Strategies.

Purpose

  • server patching is critical for maintaining a secure, stable, and compliant IT environment.
  • Patches fix vulnerabilities in operating systems, applications, and firmware.
  • Reduces risk of data breaches and unauthorized access..
  • Improves overall performance and reliability of servers.
  • Reduces exposure to zero-day vulnerabilities.

Key Procedures

  • Validation: Servers are part of patching must pass initial health checks before automation runs.
  • Automation: Zero-touch and fully automated methods available via Hippo/HPSA dashboards.
  • Pre-Checks: Scripts verify and collect Server OS Version,IP Configurations, Installed Apps, DBA, services, Route print details and etc.
  • Installation: Automated or manual installation of latest released patches for Applicable OS versions.
  • Post-Checks: Scripts confirm successful installation, up time,comparing with Pre-checks and fix any related issues.
  • Manual Method: Used if automation fails to install connect the server and proceed with Manual method patching.

Automated Deployment

  • Use HIPPO and HPSA tools for automated deployment across infrastructure.
  • Validate OS compatibility before executing automation scripts.
  • Ensure network connectivity and service availability prior to deployment.
  • Installation: Automated or manual installation of latest released patches for Applicable OS versions.
  • Review comprehensive logs post-installation to confirm successful upgrade.

Semi-Automated Deployment

  • Execute automation scripts for bulk installation across multiple servers.
  • Manually verify critical applications (Oracle, SQL, Veritas, Red Hat & Window's clusters).
  • Coordinate with respective teams to perform failover & App Stop.
  • Act accordingly upon Semi automation method end codes.

Pending Patch Check HIERM-Check for Pending WSUS Updates HIERM- Linux Update
Post-Checks GOC RM CheckServer HIERM- Linux CheckServer -post -CRQ CRQXXXXXX -force

Manual Deployment

  • For Window's Servers --> Connect the servers and install the latest updates via Window's update or Install the updates via Pre-copied updates.
  • For RHEL Servers --> Connect the servers and install the latest updates via installation commands.
  • Perform comprehensive pre- and post-maintenance verification checks.

Success Criteria

  • Latest release patch instlled n servers.
  • Servers are rebooted and there are no pending updates on server to install.
  • Server reachability.
  • Pre- checks and Post-Checks are identical.

Troubleshooting

  • During Execution servers are not reachable from Automation Tool.
  • Server is not reachable from Semi-Automation Method(HPSA).
  • Patch installation failures.
  • Server is not online & reachable post reboot.
  • Patch revert issues.
