MOP: HIERM-108 McAfee Endpoint Security Protection Upgrade

This MOP outlines a step-by-step automated and manual process for upgrading servers from McAfee VSE to ENS, ensuring proper agent installation, ePO configuration, and policy enforcement, with detailed troubleshooting and fallback methods.

Summary

This is to migrate or upgrade the McAfee VirusScan Engine into a McAfee Endpoint Security Protections and configure the Policy Orchestrator to use HUB1EPO04.

Purpose

  • Upgrade/migrate servers from McAfee VirusScan Engine (VSE) to McAfee Endpoint Security (ENS).
  • Configure servers to use Hub1EPO04 as the central ePolicy Orchestrator (ePO).
  • Ensure latest McAfee Agent and ENS version are installed.
  • Maintenance is non-impacting (should not disrupt services).

Key Procedures

  • Validation: Servers must pass McAfee Sysprep health checks before automation runs.
  • Automation: Zero-touch and fully automated methods available via Hippo/HPSA dashboards.
  • Pre-Checks: Scripts verify agent versions, ports, certificates, and VirusScan health.
  • Installation: Automated or manual installation of ENS and McAfee Agent packages (versions 5.7.6, 5.7.7, 5.7.9, 5.8.1).
  • Post-Checks: Scripts confirm successful installation, policy application, and connectivity to ePO.
  • Manual Method: Used if automation fails; involves Sysprep, certificate fixes, agent installation, and ENS setup.

Success Criteria

  • Latest ENS and McAfee Agent installed.
  • Server configured to Hub1EPO04.
  • Policies applied correctly via ePO.
  • No degradation in server state after maintenance.

Troubleshooting

  • Missing servers in ePO: Use manual tagging and agent wake-up calls.
  • Agent communication issues: Verify connectivity, enforce policies, reinstall agent if needed.
  • Update failures: Check management type; reinstall agent if not linked to ePO.
  • Removal tool: Used if ENS/VSE installation fails; requires reboot and may need multiple runs.
  • Common issues: Old McAfee services stopped, DAT files not updating, policies not applying.
