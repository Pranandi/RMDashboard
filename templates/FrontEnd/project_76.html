VMware Tools Upgrade Project Overview

The VMware Tools Upgrade Project aims to enhance the performance and functionality of virtual machines by upgrading VMware Tools to the latest supported versions across all supported operating systems. This upgrade is essential for ensuring compatibility with the underlying ESXi host versions and improving the overall user experience.

Project Objectives

  • Upgrade VMware Tools on all supported operating systems to the latest versions.
  • Ensure compatibility with the underlying ESXi host versions.
  • Minimize downtime and disruption during the upgrade process.
  • Enhance virtual machine performance and user experience.

As part of this project, we are performing VMware tools upgrade on supported Operating System.
Tools to the latest supported version supported by the Guest OS and the underlying ESXi Host. The below details rules around which VMware Tools version to use.
Vmware Tools will be upgraded based on the below Matrix for current Operating Systems.

ESX/ESXi Host Version Vmware Tools Version Guest OS Link
4.x 9.4.15 (last supported version) Linux/Windows N/A

Deploy Method via Manual Method

Note: Navigate to the HX share location \\na.msmps.net\hosting\HX\Applications\HIERM-76-Windows either from the server you are working from or from the jump box. Copy the installer VMware-Tools-XXX.exe which is required to 'c:\xfer\' on the server you are upgrading

Steps to follow:

  • Logon to the server you are working on, via RDP.
  • Navigate to the folder c:\xfer\ which is having installer file VMware-Tools-XXX.exe.
  • Run the installer file VMware-Tools-XXX.exe to upgrade VMware Tools.
  • Follow setups and choose default options When prompted.
  • For no Reboot Changes "DO NOT REBOOT SERVERS"
