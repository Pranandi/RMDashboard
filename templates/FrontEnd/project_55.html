NetBackup Upgrade Overview

Quick reference overview for NetBackup client upgrade procedures and supported environments

S.No Windows Versions RHEL Versions Opsware Versions NetBackup Versions
1 Windows 2008 R2 onwards RHEL 7 onwards Opsware 85.0.XXXXX.X NetBackup Client 10
2 Windows 2008 RHEL 6 Opsware 85.0.XXXXX.X NetBackup 8.2
3 Windows 2003 (Not Supported) RHEL 5 (Not Supported) Not Supported Not Supported
📋 Note: The upgrade version is determined by the master server version. If the master is 10.0.0, the client will be upgraded to 10.0.0; if the master is 8.2.0, the client will be upgraded to 8.2.0; if the master is 7.7.3, the client will be upgraded to 7.7.3.
⚠️ Important: For RHEL Servers, the Opsware Agent version should NOT be 85.0.94358.0. If any RHEL servers running with this version please update to latest Opsware Agent version.

Remedy Templates

  • HST - OS Patch/Agent Upgrade - HIERM - 55A - Z - NetBackup Client Upgrade Automation – Fully automated deployment with no special instructions required. Ideal for mass maintenance operations.
  • HST - OS Patch/Agent Upgrade - HIERM - 55A - NetBackup Client Upgrade – Use for customer changes with full automation capabilities. Supports servers with SAP, Oracle, or Sybase applications. Fully automated deployment option.

Upgrade Policies

  • Version 7.7.3: HIERM-55-Netbackup_7.7.3
  • Version 8.2.0: HIERM-55 NetBackup Client Upgrade
  • Version 10.0.0: HIERM-55 NetBackup Client Upgrade 10.0.0.1

Automated Deployment

  • Use HIPPO and HPSA tools for automated deployment across infrastructure
  • Validate OS compatibility before executing automation scripts
  • Ensure network connectivity and service availability prior to deployment
  • Review comprehensive logs post-installation to confirm successful upgrade

Semi-Automated Deployment

  • Execute automation scripts for bulk installation across multiple servers
  • Manually verify critical applications (Oracle, SQL, Veritas, Red Hat clusters)
  • Coordinate with database teams regarding failover procedures and service stoppage
  • Perform manual verification checks if partial failures occur during deployment

Manual Deployment

  • Download the NetBackup Client installer from the designated repository
  • Stop relevant services before installation to prevent conflicts
  • Execute the installer manually on each individual server
  • Perform comprehensive pre- and post-maintenance verification checks
  • Resolve NetBackup configuration settings and certificate issues if encountered
